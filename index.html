About

I'm a Computer Science Engineering student at Sardar Patel Institute of Technology in Mumbai, and I like building things end to end, from the database and APIs to the interface people actually use.

I work mostly in Java, Python, TypeScript and SQL, building microservices, RESTful APIs and React frontends. I've shipped full-stack projects with CI/CD pipelines, automated testing, JWT/OAuth security, and even blockchain-backed audit trails.

Most recently, I completed my final-year project, MLCloudScheduler, at the overlap of cloud and machine learning. It's a deep-learning forecaster that predicts how much computing power cloud servers will need, so they can scale up before traffic arrives instead of after. I took it from research question to tested models, statistical validation, and a full dashboard.

Outside of code, I led operations for Oculus, SPIT's annual technical festival.

  • MLCloudScheduler: Forecast-Driven Cloud Autoscaling

    Final-year project: a CNN-BiLSTM forecaster with attention and P50/P90 uncertainty outputs, trained on 101 real-world VMs, that predicts resource demand so an autoscaler can scale up before load arrives. It cuts forecast error by 20% compared with a naive baseline on 30 of 31 VMs it was tested on, and each forecast takes 3 ms, 27× faster than gradient boosting at similar accuracy. Includes a Django REST API, a React research dashboard, and 208 automated tests in GitHub Actions.
